# Timeweb: второе приложение на melissa-tech.ru

## Задача

Отдельный деплой только для прототипов из **MelissaTech2**, без пересборки всего первого монорепо.

## В панели Timeweb

1. Создать приложение **Статический сайт (HTML / CSS / JS)**.
2. Подключить Git: `https://github.com/NikitaErmilovv/MelissaTech2`, ветка `master`.
3. Настроить **префикс URL** на домене `melissa-tech.ru` для папок из этого репо (как вы уже делали для другого набора путей).
4. Включить деплой по webhook при push в `master`.

## Deploy key (для Cloud Agent)

В **Settings → Deploy keys** репозитория MelissaTech2 добавить ключ с правом записи (тот же, что для Melissa-tech.ru, если нужны пуши агента).

## После привязки

Сообщите в чате — новые прототипы будем класть в корень этого репо в отдельные папки и пушить только сюда.
